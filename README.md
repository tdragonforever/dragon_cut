# DraCut

**アプリを開く → https://tdragonforever.github.io/dragon_cut/**

スマホの Safari/Chrome で動く、無料の動画編集アプリ。Safari/Chrome で開いて「共有 → ホーム画面に追加」すると、アプリのように使えます。
動画はすべてスマホの中で処理され、どこにもアップロードされません。

## おもな機能

- 4K までの動画の読み込みと書き出し
- 複数の動画のつなぎ合わせ、分割、トランジション
- 出来上がりの比率（9:16・16:9・1:1・4:5 など）と余白の背景（黒・白・ぼかし・色）。動画は指で移動・2本指で拡大縮小
- 文字入れ（縁取り・YouTube 風のプリセット）、スタンプ、画像・動画の重ね合わせ
- フィルター・色調補正、グリーンバック合成、エフェクト
- 音楽の追加、トラックごとの音量調整、音声補正（EQ・リバーブなど）
- 編集内容の自動保存
- 4K など大きい動画は、編集中だけ軽い画質で再生（書き出しは元の画質）
