# 筋トレメモ

**アプリを開く → https://tdragonforever.github.io/dragon_cut/kintore/**

ベンチプレスなどの重さ・回数を記録するブラウザアプリ。記録は端末のブラウザに保存され、ボタン1つで Google スプレッドシートの「日次記録」シートに書き込めます。

- 日付の行があれば → その行の F 列（筋トレ）だけ上書き
- 日付の行がなければ → 日付の並び順（新しい順/古い順）に合わせて行を追加して書き込み
- 書き込む文字の形: `ベンチプレス（20kg×10、40kg×5、60kg×8）`（送る前に手で直せる）

## スプレッドシート連携の設定（最初に1回だけ）

1. 書き込みたいスプレッドシートを開き「拡張機能 → Apps Script」
2. 最初からある中身を消して、[`gas/Code.gs`](gas/Code.gs) の中身を貼り付ける
3. 6行目の `SECRET` を好きな合言葉に変えて保存
4. 右上「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 「デプロイ」→ Google アカウントの承認（「詳細 → 安全ではないページに移動」で進める。自分で作ったスクリプトなので大丈夫）
6. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピー
7. アプリの「設定」に URL と合言葉を入れて「接続テスト」

シート名・日付の列・書き込む列は設定で変えられます（初期値: `日次記録`・`A`・`F`）。
スクリプトを書き換えたときは「デプロイ → デプロイを管理 → 編集 → バージョン: 新バージョン」で更新すると URL が変わりません。

## そのほかの機能

- カレンダー（記録した日に印）、7日間・28日間・総合の負荷量、週ごとのグラフ
- 前回の記録の表示とコピー、推定1RM（重さ ×（1 + 回数/40））、自己ベスト更新の表示
- 休憩タイマー、RM計算表、種目ごとの推移グラフ
- 未送信の日をまとめて書き込み、入力後の自動書き込み（設定でオン）
- 記録のバックアップ（ファイルに書き出し/読み込み）
